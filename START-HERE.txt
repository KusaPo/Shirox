ReAnime for ShiroX — beta 0.1.1

Add one or both URLs in ShiroX > Settings > Modules:
SUB: https://raw.githubusercontent.com/KusaPo/Shirox/main/reanime-sub.json
DUB: https://raw.githubusercontent.com/KusaPo/Shirox/main/reanime-dub.json

Already installed? Refresh/update the module and confirm version 0.1.1.
If it stays on 0.1.0, remove that module entry and add the same URL again.
Reopen the title through the updated source and choose an episode.

Each main JSON loads its matching hosted JavaScript automatically.
